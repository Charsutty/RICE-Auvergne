# Art sources

No custom art assets are committed yet.

When the DDS pipeline is defined, every project-owned asset should record:

- final game path;
- source image / object;
- creator or institution;
- source URL or catalogue identifier;
- rights / license / public-domain status;
- modifications performed;
- editable master file path.

Do not assume that an asset included in RICE is freely redistributable independently: RICE credits multiple external artists and contributors. Prefer referencing dependency assets in place when possible.
