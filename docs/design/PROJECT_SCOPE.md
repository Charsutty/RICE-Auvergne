# Project scope

## Core promise

RICE: Auvergne adds historically grounded regional flavor to medieval Auvergne and its connected highland networks without becoming a map overhaul or a general France/Occitania overhaul.

## Historical weighting

### Tier 1 — Structural centers
These places and institutions should drive major mechanics and long event chains:

- Clermont and its bishops/counts
- the comital house of Auvergne and later Dauphin branch
- Brioude / Saint-Julien
- Aurillac / Saint-Géraud
- La Chaise-Dieu when chronologically appropriate

### Tier 2 — Connected powers and corridors
These should receive substantial secondary content:

- Le Puy and the Velay
- Mercœur
- Polignac
- Bourbon / northern political connections where relevant
- highland routes between Auvergne, Velay, and Gévaudan

### Tier 3 — Local frontier flavor
These should appear through targeted events, modifiers, characters, and geographic triggers rather than oversized unique systems:

- Saugues
- northern Margeride
- upper Allier crossings
- Apcher and northern Gévaudan connections

## Core gameplay pillars

1. **Competing authority** — counts, bishops, monasteries, castellans, and towns.
2. **Dynastic fragmentation** — comital division and emergence of the Dauphins.
3. **Mercœur network** — highland lordship, church careers, marriage politics, and eventual intersection with the Dauphins.
4. **Religious networks** — patronage, education, relics, monasteries, and chapters.
5. **Highland rule** — roads, winter, pastoral movement, fortifications, tolls, and frontier control.
6. **Occitan court culture** — troubadours and patronage where historically appropriate.

## MVP

The first playable slice should include:

- one small Mercœur/Saugues event cluster;
- one Clermont authority event cluster;
- one religious patronage decision;
- approximately 8–12 events total;
- English and French localization;
- no map edits;
- no custom DDS requirement for the first script test build.

## Non-goals for early versions

- map overhaul;
- wholesale landed-title replacement;
- full medieval genealogy reconstruction;
- large custom UI;
- new culture solely for flavor;
- custom military units without a strong historical case;
- DDS/art pipeline before script architecture is stable.
